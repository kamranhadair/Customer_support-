# Subscription Plans

## Overview

We offer four tiers designed for individuals, small teams, and enterprises.

---

## Free Plan

**Price:** $0/month

**Includes:**
- Up to 500 API calls/month
- 1 user seat
- Community support (forum only)
- Basic analytics dashboard
- 1 GB storage

**Limitations:**
- No SLA guarantee
- No custom integrations
- No priority queue access

---

## Starter Plan

**Price:** $29/month (billed monthly) or $24/month (billed annually — save 17%)

**Includes:**
- Up to 10,000 API calls/month
- Up to 3 user seats
- Email support (48-hour response SLA)
- Full analytics dashboard
- 10 GB storage
- 2 custom integrations

---

## Pro Plan

**Price:** $99/month (billed monthly) or $79/month (billed annually — save 20%)

**Includes:**
- Up to 100,000 API calls/month
- Up to 15 user seats
- Priority email + chat support (4-hour response SLA)
- Advanced analytics & reporting
- 100 GB storage
- Unlimited integrations
- API access for automation

---

## Enterprise Plan

**Price:** Custom pricing — contact sales@example.com

**Includes:**
- Unlimited API calls
- Unlimited user seats
- 24/7 dedicated support with 1-hour SLA
- Custom SLA agreements
- Dedicated infrastructure
- SSO/SAML integration
- Compliance reports (SOC2, GDPR)
- Custom data retention

---

## Upgrading / Downgrading

- **Upgrades** take effect immediately. The price difference is prorated.
- **Downgrades** take effect at the start of the next billing cycle.
- **Annual ↔ Monthly** switches take effect at the next renewal.

## Adding Seats

Extra seats can be purchased at:
- Starter: $8/seat/month
- Pro: $15/seat/month
- Enterprise: Included in contract
